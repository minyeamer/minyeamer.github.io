코드잇(Codeit) 수강 후기 - SKT 영위크 2주 무료 이용

2026. 10. 26. 01:37 • 읽는데 4분

코드잇 | 5분마다 인생이 바뀐다

웹 개발, 데이터 분석, AI, 디자인 등 IT 역량 코드잇 하나로 완벽하게

코드잇

최근 2주간 코드잇이라는 IT/코딩 교육 플랫폼에서 프론트엔드 중심의 과정을 들었습니다.

수강 배경 #

저는 Python과 SQL 중심의 기술 스택을 가지고 데이터 직무에서 경력을 가지고 있지만, 최근 바이브코딩으로 웹사이트 개발을 시도하면서 프론트엔드와 백엔드 분야에서 전문성이 부족한 것을 느끼고 있었습니다. 특히, 개인용 웹사이트를 만드는데 그치지 않고 오픈소스 프로젝트에도 바이브코딩으로 제가 원하는 UI를 추가했었고, 이 과정에서 리뷰어에게 검수가 덜 된 코드를 제출해 주의를 받은 후 웹 개발 지식에 대한 필요성을 체감했습니다.

그러던 중, 제가 가입한 SKT에서 월마다 TDAY라는 이벤트를 제공하는데, 청소년/청년 고객에게만 제공하는 Young Week 혜택에서 코드잇의 2주 무료 이용 쿠폰을 제공해 주어서 이번에 프론트엔드를 공부해 보기로 했습니다.

학습 결과 #

2주가 지난 시점에서 후기 글을 작성하기로 해서 가입 초기 화면이나 쿠폰 등록 화면을 스크린샷으로 남기진 못했습니다. 2주라는 짧은 시간에 최대한 뽑아먹어야겠다고 생각해서 시간날 때마다 코드잇에 접속해서 강의를 들었습니다. 멤버십이 끝난 시점에서는 22개의 토픽과 886개의 레슨을 완료했고, 처음 목표였던 React 로드맵으로 짜여진 모든 토픽을 완강했습니다.

로드맵 #

코드잇에서는 데이터 분석, 디자인, 머신러닝/딥러닝 등 다양한 카테고리로 분류된 강의들을 제공하는데, 저는 웹 개발 카테고리에서 "React로 배우는 실전 프론트엔드 개발" 로드맵을 따라갔습니다. 백엔드 쪽에서는 Django, Node.js, Spring 로드맵 등을 제공했습니다.

로드맵에는 여러 토픽을 학습하기 좋은 순서대로 정렬해서 안내합니다. 앞선 로드맵 목록 아래서 개별 토픽을 선택해 수강할 수도 있는데, 토픽 간에 학습 순서를 구별하기 어려운 저 같은 사람은 로드맵을 따라가는게 생각할 시간을 줄이고 편했습니다.

로드맵 따라가기를 클릭하면 재생목록으로 로드맵이 등록됩니다. 새로 추가한 React 재생목록에 들어가면 로드맵에 포함되는 토픽들이 순서대로 나열되어 있습니다. 초반에는 HTML이나 JavaScript 등 기초적인 강의로 시작하여 빠르게 스킵하면서 완료했고, React 부분부터 본격적으로 들었습니다.

강의 경험 #

레슨이라는 단위로 나눠진 강의는 동영상, 퀴즈, 실습 등 다양한 방식으로 개념을 익히고 코딩 경험을 쌓을 수 있는 경험을 제공합니다.

기본적인 동영상 강의는 완료하지 않은 상태에서도 배속이나 스킵 등의 기능이 주어지고, 직접 완료 버튼을 클릭하면 강의를 다 듣지 않고 다음 강의로 넘어갈 수 있어서 아는 내용은 빠르게 스킵할 수 있습니다. 또한, 좌측 상단의 목록 아이콘을 클릭해서 원하는 제목의 강의로 바로 넘어갈 수도 있습니다.

동영상 강의를 마치면 관련 내용을 실습할 수 있게 에디터 환경으로 넘어갑니다. 프로그래밍 언어를 학습하는 과정에서는 코드를 작성하고 채점하기 버튼을 통해 출력 결과가 올바르게 나오는지 시스템이 검사해서 완료 처리를 진행한다면, React와 같은 웹사이트 실습 과정에서는 개발용 서버를 직접 실행해서 작성한 코드가 올바른지 셀프 체크해서 실습을 완료 처리합니다.

개발용 서버 실행 시 에디터 하단의 터미널에서 npm run dev와 같은 미리 주어진 스크립트를 실행하여 웹 페이지를 열 수 있습니다.

터미널에 출력된 주소로 이동하거나 "웹 페이지 열기" 버튼을 클릭하면 제가 작성한 코드를 시각화해서 확인하고 직접 조작해 볼 수도 있습니다.

수강 후기 #

제가 들었던 React 강의에서는 useState, useEffect와 같은 React의 기본 Hook부터 styled-components나 React Query와 같은 라이브러리 사용법도 배웠습니다. 다른 후기에서는 내용이 쉽고 실무에는 맞지 않다는 의견이 있었는데, 저처럼 단기간에 내용을 효과적으로 습득하는데는 이정도 난이도가 적당했다고 생각합니다.

하지만, 제가 보던 React 코드들은 전부 TypeScript로 작성되었는데 코드잇에서는 JavaScript로 React를 배우고 나중에 이를 보강하는 하나의 토픽만 제공하다 보니 확실히 실무에 바로 적용하기는 어려워 보였습니다.

월간으로 2만원 정도의 가격이라면 연장해서 사용해보려고 했지만, 일단 1개월치 플랜도 확인되지 않고 연간으로도 월 4만원이라는 다소 접근성 높은 가격이라서 아쉽게도 직접 결제해서 사용헤야겠다는 생각은 들지 않았습니다. 특히, 저는 평일에는 거의 시간을 내지 못하고 휴일에만 몰아서 강의를 듣다보니 이러한 구독형 플랜은 절반 정도 손해를 볼 생각으로 들어야 해서 더욱이 결제하기 어려운 가격이었습니다.

앞으로 또 추가적인 무료 이용 쿠폰이 제공된다면 Node.js와 같은 백엔드 기술을 배워볼 예정입니다. 확실히 초보자의 관점에서 수강 경험은 인프런과 같이 단순히 동영상 강의만 제공되는 방식보다 몰입이 잘 되었습니다. 다만, 에디터에서 자동 완성 등의 기능이 제한적으로 제공되어서 메모장으로 코딩하는 느낌이 있었습니다.

과거에 수강한 경험이 있는 구름EDU에서 비슷하게 에디터로 실습하는 경험을 제공했던 걸로 기억하는데, 개인적으로는 이렇게 직접 코드를 작성하고 실행하여 내가 작성한 코드가 어떤 결과를 보여주는게 쉽고 효과적으로 이해할 수 있는 방법인 것 같습니다.

2주간 코드잇에 몰입하면서 React의 기본적인 개념을 완벽히 이해했습니다. 무료로 이러한 기회를 제공해주셔서 감사합니다.
